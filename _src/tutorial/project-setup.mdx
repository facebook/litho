## 2. Project dependencies

<OssOnly>

To use Litho in your own app, add the dependencies to your module's `build.gradle`:

<VersionedCodeBlock language="groovy" code={`
dependencies {
  implementation 'com.facebook.litho:litho-core:{{site.lithoVersion}}'
  implementation 'com.facebook.litho:litho-widget-kotlin:{{site.lithoVersion}}'
}
`} />

From Litho 0.51.0, Kotlin code that calls Litho hooks also has to be built with the Litho Gradle plugin. Apply it with the same version as the Litho dependencies, and add `mavenCentral()` to `pluginManagement.repositories` in `settings.gradle`:

```groovy
plugins {
  id 'com.facebook.litho' version '<Litho version>'
}
```

</OssOnly>

<FbInternalOnly>

The following dependencies are generally required in your module's `BUCK` file to use Litho:

<VersionedCodeBlock language="groovy" code={`
deps = [
    "//fbandroid/java/com/facebook/litho/sonar:sonar",
    "//fbandroid/libraries/components/litho-core/src/main/java/com/facebook/litho:litho",
    "//fbandroid/libraries/components/litho-widget/src/main/kotlin/com/facebook/litho/kotlin/widget:widget",
    "//fbandroid/libraries/components/litho-widget/src/main/kotlin/com/facebook/litho/widget/canvas:canvas",
    "//fbandroid/libraries/components/litho-widget/src/main/kotlin/com/facebook/litho/widget/collection:collection",
]
`} />

</FbInternalOnly>

The required dependencies are already set up for your sample project.

## 3. Testing your setup

:::info
This tutorial is focused on Kotlin API using KComponents. Spec API is legacy and should only be considered to maintain existing code.
:::

<FbInternalOnly>

You can navigate to the project by having Android Studio open with fbsource and clicking the icon below on the file preview.

</FbInternalOnly>

```kotlin file=sample/src/main/java/com/facebook/samples/litho/onboarding/MyActivity.kt start=start_example end=end_example
```

The command to build and install the app is:

<OssOnly>

```sh
./gradlew :sample:installDebug
```

</OssOnly>

<FbInternalOnly>

```sh
buck2 install -r litho
```

</FbInternalOnly>

Running the app navigate to "Tutorial" -> "1. Hello World" where you'd see the preview of this activity.
You can make changes to this file throughout the next sections and run the app to monitor changes.

</FbInternalOnly>
