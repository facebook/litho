NewStickyHeaderController

class NewStickyHeaderController(layoutInfo: LayoutInfo, adapter: CollectionPrimitiveViewAdapter) : RecyclerView.OnScrollListener

A controller that manages sticky headers in a RecyclerView by tracking scroll events and maintaining a floating header view that stays visible at the top when scrolling past sticky items.

This controller uses a linked list structure to efficiently track sticky header positions and handles header transitions, stacking animations, and visibility management.
