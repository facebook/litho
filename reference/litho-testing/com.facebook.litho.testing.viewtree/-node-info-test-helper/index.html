NodeInfoTestHelper

object NodeInfoTestHelper

Helper class for extracting NodeInfo from Views and creating predicates/extractors for testing NodeInfo properties.

This class provides utilities for testing accessibility properties and other NodeInfo fields in Litho component hierarchies. It centralizes the logic for extracting NodeInfo from views via the COMPONENT_NODE_INFO_ID tag.

Usage example:

// Get NodeInfo from a view
val nodeInfo = NodeInfoTestHelper.getNodeInfo(view)

// Create a predicate to check for a specific accessibility role
val predicate = NodeInfoTestHelper.createPropertyPredicate(
    "accessibilityRole",
    "android.widget.Button"
) { it.accessibilityRole }

// Create an extractor for debug output
val extractor = NodeInfoTestHelper.createPropertyExtractor(
    "accessibilityRole"
) { it.accessibilityRole }
