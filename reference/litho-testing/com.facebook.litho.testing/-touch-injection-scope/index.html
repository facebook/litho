TouchInjectionScope

class TouchInjectionScope

Dispatches well-formed MotionEvent streams through a real View.dispatchTouchEvent chain.

View.performClick() invokes the click listener directly, so it only proves a listener is installed. Use this instead to exercise hit testing, touch slop, press state, long-press scheduling, TouchDelegates, and ACTION_CANCEL from an intercepting ancestor.

Coordinates are in target's coordinate space.
