fun View.performTouchInput(block: TouchInjectionScope.() -> Unit): Boolean

Runs block against a TouchInjectionScope targeting this view. Coordinates inside block are in this view's coordinate space.

fun TestLithoView.performTouchInput(block: TouchInjectionScope.() -> Unit): Boolean

Runs block against a TouchInjectionScope targeting the rendered LithoView, so a gesture enters at the root and is hit-tested down the real hierarchy. Coordinates are in the LithoView's space.

Unlike LithoTestRule.act, this does NOT idle the loopers afterwards: it dispatches straight into View.dispatchTouchEvent and returns. That is what a characterization test wants, since idling would hide ordering. If the gesture's handler schedules work — a state update, a re-render — call LithoTestRule.idle() before asserting, or the assertion races it.
