useLegacyTextCustomEllipsisOffsetFix

With performant truncation, cut a custom ellipsis at the offset Paint.getOffsetForAdvance returns instead of one character before it, like legacy Text with enableFixForTextEllipsisOffset, stepping back while it doesn't fit. Off by default so existing RichText users keep their current truncation behavior.

useResolvedLayoutDirection

Resolve text direction and LAYOUT_START/LAYOUT_END from this component's Litho (Yoga) layout direction instead of the locale, matching Litho's legacy Text. Off by default so existing RichText users keep their locale-based behaviour; see com.facebook.rendercore.text.RichTextPrimitive for why.
