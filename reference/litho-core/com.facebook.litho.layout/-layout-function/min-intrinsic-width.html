minIntrinsicWidth

open fun IntrinsicLayoutScope.minIntrinsicWidth(measurables: List<Measurable>, height: Int): Int

The narrowest this container can be at height without its content breaking out of it.

This is what a container contributes to the CSS Flexbox §4.5 automatic minimum, so a Row that squeezes it cannot take it below this. Nothing here reaches it: Litho asks that question through a second measure function, which the diffs above register.
