MeasureScope

@ExperimentalLithoApi
class MeasureScope : IntrinsicMeasureScope

Receiver for LayoutFunction.measure, and where a pass leaves what it works out: it asks its children as IntrinsicMeasureScope does, measures them, and declares.

A layout function reports through the scope rather than by returning a value, so everything a pass produces arrives by one route and a later addition needs no new return type.
