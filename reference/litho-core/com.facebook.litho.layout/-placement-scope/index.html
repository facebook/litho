PlacementScope

@ExperimentalLithoApi
class PlacementScope

Receiver for the placement pass.

A child that is never placed occupies no space and will not be mounted. Declining to place is therefore how a container drops a child: measuring one to see whether it fits and then leaving it out costs its subtree nothing.
