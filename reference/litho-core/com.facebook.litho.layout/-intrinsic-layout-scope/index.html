IntrinsicLayoutScope

@ExperimentalLithoApi
class IntrinsicLayoutScope : MeasuringScope

Receiver for a LayoutFunction's intrinsic-size questions.

Separate from LayoutScope so an intrinsic query cannot place anything: it asks what a container would do. A LayoutScope holds its placement block unevaluated and only the framework runs it, so asking for an intrinsic size cannot place a child or fire a side effect the block holds.
