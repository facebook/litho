Placeable

@ExperimentalLithoApi
class Placeable

A child that has been laid out and knows its size, but not yet where it sits.

Only the framework can make one — the constructor is internal — which is what lets PlaceableScope.place trust childIndex. place is an extension on this type rather than a function taking an index, so the index travels with the placeable and cannot be fabricated to place a child at the wrong slot.
