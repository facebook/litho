const val ResolveVersion: String

Monotonically increasing version identifying a specific resolve pass within a component tree. Incremented by ComponentTree on each setRoot or state update that triggers a resolve. Present on resolve-phase events (LithoDebugEvent.ComponentTreeResolve, LithoDebugEvent.ComponentRendered) and also on layout-phase events to enable cross-phase correlation.
