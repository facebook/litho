onInvisible

fun Style.onInvisible(visibleWidthRatio: Float = 0.0f, visibleHeightRatio: Float = 0.0f, callback: (InvisibleEvent) -> Unit): Style

Registers a callback to be called when a Component becomes fully invisible (e.g. scrolled off or unmounted).

Parameters

visibleWidthRatio

Ratio of the Component width for the invisibility callback to be dispatched. Default is 0f.

visibleHeightRatio

Ratio of the Component height for the invisibility callback to be dispatched. Default is 0f.

callback

Callback to be invoked when the component becomes invisible.
