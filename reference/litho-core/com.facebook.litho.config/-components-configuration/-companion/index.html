When true, the shared Litho com.facebook.yoga.YogaConfig (built by com.facebook.litho.yoga.LithoYogaFactory.createYogaConfig) clears the MinSizeUndefinedInsteadOfAuto errata bit, enabling CSS Flexbox §4.5 automatic minimum sizing for every flex item.
