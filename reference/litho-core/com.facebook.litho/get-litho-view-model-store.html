getLithoViewModelStore

@ExperimentalLithoApi
@UiThread
fun ViewModelStoreOwner.getLithoViewModelStore(): LithoViewModelStore

Returns the thread-safe Litho ViewModel store retained by this AndroidX owner.

Repeated calls for the same owner return the same store. The owner controls its lifetime and closes the store when its AndroidX androidx.lifecycle.ViewModelStore is cleared. Acquire the store on the main thread before passing it to a ComponentTree that may be built or resolved on another thread.

Throws

IllegalStateException

if this owner is a destroyed LifecycleOwner.
