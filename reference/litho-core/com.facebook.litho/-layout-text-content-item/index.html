LayoutTextContentItem

class LayoutTextContentItem(layout: Layout, val text: CharSequence, val fullText: CharSequence, isExplicitlyTruncated: Boolean, val color: Int = layout.paint.color, isMounted: () -> Boolean = { true }) : TextContent.Item

A TextContent.Item read from the Layout a text component draws, shared by Litho's legacy text drawable and RenderCore's text view so both report text the same way.

Parameters

text

the text that is mounted; for a custom ellipsis, the already-truncated string.

fullText

the text the component was given, before any truncation.

isExplicitlyTruncated

whether the component pre-truncated the text for a custom ellipsis.

color

the color the text is drawn in, when it differs from the layout's paint.

isMounted

whether layout is still the one the component draws; span bounds are empty once it isn't, as they were before this class was shared.

open override val displayedText: CharSequence

The text actually drawn on screen. For a standard ellipsize the ellipsized run is replaced with the ellipsis glyph ("…"), reconstructed from the layout's per-line ellipsis metadata (getEllipsisStart/getEllipsisCount) — exactly the substitution the platform makes when drawing the line. For a custom ellipsis it is the pre-truncated text with the custom ellipsis already baked in. Equals fullText when nothing is truncated.
