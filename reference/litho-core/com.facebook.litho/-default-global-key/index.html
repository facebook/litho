DefaultGlobalKey

class DefaultGlobalKey(val key: Int, val position: Int, val parent: GlobalKey?) : GlobalKey

Memory-efficient linked structure for auto-generated keys. Used when the config flag is on and no manual key is present in the ancestry.

key is the component's typeId, position is the sibling index (0 = first of this type).

buildKeyString produces the same format as the current string concatenation: "parentKey,typeId" for position 0, "parentKey,typeId!N" for position N 0.
