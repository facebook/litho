RCTextViewTextContent

class RCTextViewTextContent : TextContent

Reports the text of an RCTextView mounted in a ComponentHost, so the host's TextContent covers primitive text the same way it covers Litho's legacy text drawable.

isMatchedThroughHost

val isMatchedThroughHost: Boolean

Whether test lookups should match this text through its host, like legacy Text which draws into its host. True for Litho's Text, unless legacy Text would have had a wrapper host of its own (click handler, view tag, focusable, a11y, ...): then the text view stands in for that wrapper. Direct primitive users are always matched on the text view, and so is hidden text, so a visible-text lookup checks the text view's own visibility rather than its host's.
