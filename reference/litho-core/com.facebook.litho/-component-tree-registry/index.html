ComponentTreeRegistry

object ComponentTreeRegistry

Thread-safe singleton registry that holds weak references to all ComponentTree instances that are still in memory, including released ones that have not been garbage collected yet.

Gated by enabled so it is zero-cost when disabled. The flag is set by com.facebook.litho.hotreload.LithoHotReloadHandler.install and by Litho Observability in debug and perf builds.
