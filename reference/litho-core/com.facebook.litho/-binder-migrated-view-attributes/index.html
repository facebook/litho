BinderMigratedViewAttributes

class BinderMigratedViewAttributes

Contains the 21 view attribute properties that have been migrated to the onBindViewWithDescription binder pattern behind the useViewStyleBinders config flag.

When the binder migration is fully rolled out and useViewStyleBinders is removed, this entire class can be deleted.
