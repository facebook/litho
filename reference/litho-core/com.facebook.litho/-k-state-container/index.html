KStateContainer

class KStateContainer : StateContainer

The StateContainer implementation for Kotlin components. Tracks all state defined by useState calls for the same component (see KState for usage). Immutable by default: every copy-on-write mutation returns a new instance with the prior entries copied and one entry added or replaced. The one exception is the transient render-owned fork (mutableForkWith / mutateInPlace): a render forks a single mutable copy of its component's container and then mutates that copy in place for the rest of the pass, tracked by ComponentScope.ownedStateContainer. Committed/shared containers are never mutated in place - a subsequent render forks them.

Each entry carries its HookKey; lookup is an O(N) linear scan over the list using HookKey equality via getByHookKey/hasHookKey/copyAndMutateByHookKey. Interning lets equality short-circuit on reference identity, so the scan is essentially a pointer compare.

fun mutableForkWith(hookKey: HookKey, newValue: Any?, deps: Array<*>?): KStateContainer

Fork a single mutable copy of this container with hookKey added or replaced. The returned container's backing is a live ArrayList (not wrapped), so the owning render can keep mutating it in place via mutateInPlace for the rest of the pass. The caller (KState) records the result as ComponentScope.ownedStateContainer so subsequent mutations this pass route to mutateInPlace.
