BinderUpdateTracer

class BinderUpdateTracer : UiStateReadRecords.BinderEventListener

A UiStateReadRecords.BinderEventListener that tracks per-binder shouldUpdate results and bind durations for observability.

Data is accumulated in a thread-local map keyed by renderUnitId. This data is drained by the BinderUpdateDetector when it receives the corresponding RenderUnitUpdated debug event (which fires on the same thread, immediately after all binder operations complete).

When isEnabled is false (default), callbacks are no-ops with negligible overhead (one static field read per call).
