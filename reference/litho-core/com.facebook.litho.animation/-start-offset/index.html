StartOffset

@JvmInline
value class StartOffset

A one-time shift of a repeating animation's start time, used to stagger or delay loops (see repeatable / infiniteRepeatable).

Unlike a tween's delay — which is baked into the spec and so repeats every cycle — a StartOffset applies only once, to the first cycle:

  • StartOffsetType.Delay holds the animation at its start value for offsetMillis before the first cycle begins.

  • StartOffsetType.FastForward starts the animation immediately, already offsetMillis into its cycle. Because the cycle is periodic, this is a persistent phase shift across all cycles — the natural way to stagger several otherwise-identical loops.
