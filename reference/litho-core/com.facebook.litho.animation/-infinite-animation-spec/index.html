InfiniteAnimationSpec

interface InfiniteAnimationSpec<T> : AnimationSpec<T>

An AnimationSpec that never settles — it loops for the lifetime of its owner. Produced by infiniteRepeatable and consumed by useInfiniteAnimation. Deliberately NOT a FiniteAnimationSpec, so the type system keeps it out of target-settling APIs that depend on completion.
