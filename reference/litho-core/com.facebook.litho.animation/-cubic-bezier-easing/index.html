CubicBezierEasing

class CubicBezierEasing(x1: Float, y1: Float, x2: Float, y2: Float) : Easing

An Easing defined by a cubic bezier curve.

The control points (x1, y1) and (x2, y2) define the shape of the curve, where x represents time and y represents progress. The start point (0, 0) and end point (1, 1) are implicit.

Delegates to Android's PathInterpolator for efficient native evaluation.

// Material Design emphasized easing
val emphasized = CubicBezierEasing(0.2f, 0.0f, 0.0f, 1.0f)
