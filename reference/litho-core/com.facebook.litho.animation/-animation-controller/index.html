AnimationController

object AnimationController

Coalesces active FrameDrivenAnimations onto a shared AnimationFrameDriver.

On each frame, all registered animations are ticked via FrameDrivenAnimation.onFrame. This controller has no knowledge of the state update mechanism or mounted content writes. Those are the responsibility of the registered animation.

Frame Coalescing

A single driver callback ticks all active animations per frame, avoiding per-animation callback overhead.

Testability

Tests can temporarily swap the underlying frameDriver with withFrameDriverForTest to advance frame delivery and frame time deterministically.
