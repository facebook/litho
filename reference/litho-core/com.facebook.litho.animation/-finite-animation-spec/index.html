FiniteAnimationSpec

interface FiniteAnimationSpec<T> : AnimationSpec<T>

An AnimationSpec that completes in finite time: it eventually reaches its target and settles.

Target-settling APIs (useAnimatedValue, useAnimationGroup, Style.transition, enter/exit transitions, SizeTransform) require finite specs, because their completion-dependent behavior — onSettled, retained-content unmount, converging to the resolved mount value — only works if the animation actually finishes. Infinite specs are excluded by type (InfiniteAnimationSpec is not a FiniteAnimationSpec).
