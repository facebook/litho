StyleTransitionScope

@ExperimentalLithoApi
class StyleTransitionScope

Defines the host properties animated by Style.transition.

Each property is optional. Set a property to an AnimationSpec to animate changes for that property, or set it to null in a later composed transition to remove a previous declaration.

Bounds animate per axis through x, y, width, and height, or as groups through position, size, and bounds. Whether a size change reflows siblings is a mode of the whole host, set only by size and bounds: their functions take reflow, and their properties are visual. The per-axis properties and position refine an axis's spec without changing that mode, so size(spring(), reflow = true); height = tween() still reflows, with height on the tween.

Reading a group property returns its spec only when every axis it covers shares that spec, and null otherwise: after bounds = spring(); height = tween(), bounds and size read null while position still reads the spring.
