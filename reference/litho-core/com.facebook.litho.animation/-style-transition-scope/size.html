fun size(spec: FiniteAnimationSpec<Float>, reflow: Boolean = false)

Animates the host's size with spec, like the size property.

When reflow is true, the size change drives a real per-frame Yoga relayout, as described for the bounds function. When reflow is false this is identical to setting the size property. Either way the host's own position is not animated; declare position too, or use bounds.

var size: FiniteAnimationSpec<Float>?

Animates the host's mount-space size: width and height.

A visual mount animation, like the bounds property: layout is already final while the size animates. Use the size function with reflow = true when siblings should follow every frame.
