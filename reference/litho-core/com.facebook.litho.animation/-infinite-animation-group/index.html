InfiniteAnimationGroup

@ExperimentalLithoApi
class InfiniteAnimationGroup

The per-render handle returned by useInfiniteAnimationGroup and the public surface for declaring a container's loops (animateFloat, animateDimen, …).

Each call to useInfiniteAnimationGroup creates a fresh InfiniteAnimation, isolating per-render bookkeeping (the slot counter, pending descriptors) from the shared InfiniteAnimationGroupState. Declaring a loop allocates no AnimatedValue and mutates nothing: it records an InfiniteSlotDescriptor and returns a stable Value handle.
