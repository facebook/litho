fun ComponentScope.useAnimatedColor(targetValue: Color, spec: FiniteAnimationSpec<Color> = spring(), trigger: AnimationTrigger = AnimationTrigger.Immediate, label: String = "color"): Value<Color>

Animates a Color value with per-channel interpolation, automatically starting a new animation whenever targetValue changes.

Return

A Value containing the current interpolated color.

Parameters

targetValue

The color to animate toward. Changes trigger new animations.

spec

The animation specification. Defaults to spring.

trigger

Controls when the animation begins receiving frame callbacks. Defaults to AnimationTrigger.Immediate.

label

Optional label for debugging and tracing attribution.
