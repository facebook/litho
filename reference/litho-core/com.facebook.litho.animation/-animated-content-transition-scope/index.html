AnimatedContentTransitionScope

@ExperimentalLithoApi
class AnimatedContentTransitionScope<T>

Scope for AnimatedContent.transitionSpec. Exposes the initialState and targetState of the current transition (so the spec can vary by direction, e.g. via isTransitioningTo or slideIntoContainer) and collects the enter/exit specs that make up the ContentTransform.

The spec lambda declares the transition by setting enter / exit; anything not set defaults to None. Assigning the same property more than once is last-wins, matching the per-effect merge semantics of EnterTransition.plus.

Slides the target content into the container, entering from the edge opposite towards and moving in the towards direction to its resting position. Unlike slideInHorizontally / slideInVertically (which offset by the content's own size), the slide is measured across the container's bounds. Only meaningful inside AnimatedContent's transitionSpec.
