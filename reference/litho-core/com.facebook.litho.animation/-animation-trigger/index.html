AnimationTrigger

sealed interface AnimationTrigger

Strategy interface that controls when an animation begins receiving frame callbacks.

Inspired by CoroutineStart / SharingStarted, this lets callers decouple animation setup from animation start. In collections with hundreds of items, animations can run to completion while items are still off-screen. AnimationTrigger solves this without per-item state updates.
