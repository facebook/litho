Parameters

alignContent

Defines how the lines of children are distributed along the cross-axis when there is extra space (only applies when wrap is enabled). Uses YogaAlign values such as FLEX_START, CENTER, FLEX_END, STRETCH, SPACE_BETWEEN, or SPACE_AROUND.

alignItems

Defines the default alignment for children along the cross-axis.

justifyContent

Defines how children are distributed along the main axis (horizontal for Row).

wrap

Controls whether children wrap to multiple lines when they exceed the container's size.

isReversed

If true, reverses the order of children along the main axis (right-to-left instead of left-to-right).

gap

Specifies the spacing between children. Applied uniformly between all adjacent children in the container. Resolved to pixels at layout time.

mainAxisGap

Spacing between children along the main axis (horizontal for Row). Takes precedence over gap if both are specified.

crossAxisGap

Spacing between wrapped lines along the cross axis (vertical for Row). Only applies when wrap is enabled. Takes precedence over gap if both are specified.

style

The Style to apply to this Row for additional layout and visual properties.

customSimpleName

Overrides the component's Component.getSimpleName (defaults to "Row"). Preserves the debug/finder identity of legacy Row.create(c, name) call sites migrated onto this DSL; leave null for the standard "Row" name.

init

A lambda with FlexboxScope receiver for adding children to this Row using FlexboxScope.child.
