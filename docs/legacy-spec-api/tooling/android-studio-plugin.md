## Litho Spec API IDE Plugin

In 2019, the capabilities of the Litho generative Spec API were expanded with the addition of the Litho IDE plugin. This plugin was specifically designed to enhance the functionality of IDE actions for generated code.

The plugin offered comprehensive support for key features including:
- **Code Navigation** - Navigate between Spec classes and their generated components
- **Code Completion** - Auto-complete for Spec annotations and generated APIs
- **Editor Warnings** - Highlight issues in Spec definitions
- **File Templates** - Create new Spec files with boilerplate
